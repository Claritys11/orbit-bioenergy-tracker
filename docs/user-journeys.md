# User Journeys

1. Public visitor understands ORBIT and opens Live Impact: land on `/`, read problem and loop, open `/transparency`, inspect confidence labels.
2. Public visitor verifies a QR batch: scan label or open `/trace/[token]`, see public batch code, status, accepted mass, timeline, and data classification.
3. School representative learns how to participate: open `/partners`, read school role, safety boundaries, onboarding requirements, and CTA.
4. Canteen staff registers a waste batch: login, open Create Batch, enter source/category/weight/storage/photo URL, generate QR, prepare pickup.
5. Operator schedules pickup and inspects batch: login, open Pickups, schedule route, confirm delivery, open Inspections, enter accepted/rejected mass.
6. Operator records conversion and verified gas: choose accepted batches, record verified gas, operational use, reserve, digestate, and measurement source.
7. ORBIT calculates allocation: open conversion detail, inspect simulation, finalise allocation version from verified allocatable gas.
8. School monitors allocation: school admin dashboard shows accepted waste, contamination, allocation, fulfilment, and savings assumptions.
9. Community partner monitors benefit: community dashboard focuses on allocation, usage, pending fulfilment, and public-safe local impact.
10. Administrator reviews data quality and audit records: super admin dashboard surfaces warnings, audit activity, facility validation, and config status.
