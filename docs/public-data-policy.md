# Public Data Policy

## Public
Aggregated waste totals, public organisation names, accepted/rejected mass, contamination rate, verified gas, allocation, fulfilment status, partner status, methodology, references, and reporting periods.

## Aggregated
System-wide waste flow, allocation pools, contamination trends, digestate totals, and activity feed with no personal names or exact routes.

## Organisation Only
School batch ownership, internal operational notes, school-specific financial assumptions, and private batch details.

## Operator Only
Inspection notes, route planning, vehicle assignment, facility operation notes, raw sensor configuration, and maintenance work details.

## Administrator Only
Private audit diffs, user email, role changes, settings changes, sensitive corrections, and unpublished financial records.

## Sensitive Information
Never expose student identity, personal email, phone number, private photos, exact route, vehicle identity, security weakness, detailed safety incident, or authentication details on public pages.
