# Information Architecture

## Public Navigation
Top-level public routes:
- `/` Overview and story
- `/transparency` public-safe monitoring dashboard
- `/impact` impact dimensions and limits
- `/methodology` formulas and data confidence
- `/partners` partner roles and onboarding
- `/about` project background and challenge fit
- `/sources` source-backed claims
- `/trace/[token]` safe QR trace
- `/login` operational access

Landing anchors: overview, problem, how-it-works, purity-to-power, live-impact, transparency, allocation, partners, about, safety, faq.

## Private Navigation
Groups:
- Overview: Dashboard
- Waste Operations: Waste Batches, Create Batch, QR Scanner, Pickups, Inspections
- Energy Operations: Conversion Cycles, Allocations, Fulfilment
- Reports: Impact, Sustainability
- Management: Facilities, Organisations and Users, Safety, Audit Logs, Settings

Groups are hidden when no visible items are allowed for the current role.

## Mobile Behaviour
Public mobile navigation uses a disclosure menu. Private mobile navigation uses grouped task links instead of a long horizontal list.

## Role Visibility
Students see safe traceability and education. Operators see pickup, inspection, conversion, allocation, fulfilment, safety. Super admins see system and audit. School users see school impact and batch status. Community partners see allocation and fulfilment reports.
